# SCHub.vn - Supply Chain Knowledge Hub

Website chia sẻ kiến thức Supply Chain thực chiến cho doanh nghiệp Việt Nam.

## 🚀 Tech Stack

- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS + Tailwind Merge
- **Routing:** React Router DOM v6
- **Animation:** Framer Motion
- **SEO:** React Helmet Async
- **Icons:** Lucide React

## 🛠️ Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build

# Run lint
npm run lint

# Preview production build
npm run preview
```

## 📁 Cấu trúc

```
src/
├── components/       # Reusable components
│   ├── layout/    # Navbar, Footer, SiteLayout
│   └── ui/       # UI components (Button, Card,...)
├── pages/         # Page components
│   ├── Home.tsx
│   ├── Articles.tsx
│   ├── ArticleDetail.tsx
│   ├── Solutions.tsx
│   ├── Checklist.tsx
│   ├── learning/   # Learning Hub pages
│   └── ...
├── lib/          # Utilities
└── styles/       # Global styles
```

## 📝 Nội dung

- **Learning Hub:** Supply Chain Foundation, Demand Analysis, Demand Management, Forecasting, S&OP, Operations Planning & Control
- **Solutions:** Tài nguyên, Sản phẩm số, Công cụ, Dịch vụ, Checklist
- **Blog:** Bài viết chia sẻ kinh nghiệm Supply Chain thực chiến
